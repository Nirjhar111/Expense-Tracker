# Expense-Tracker

##  Python Expense Tracker (CLI)

A beginner-friendly [Python command-line Expense Tracker] that allows users to record expenses, categorize them, save them in a file, and view a summary of spending based on a monthly budget.

Features :-

1) Add a new expense (name, amount, category)
2) Categories include: Food, Home, Work, Fun, Misc
3) Saves all expenses to a CSV file (`expenses.csv`)
4) Reads saved expenses and generates:

   Total expenses
   Expense summary by category
   Remaining budget
   Estimated daily budget for the rest of the month
 Color-coded output for better visibility
 Clean and modular code structure (`Expense` class included)

Project Structure :-

```
📦 Expense Tracker
├── expense.py               # Expense class (name, category, amount)
├── expense_tracker.py       # Main CLI logic
└── expenses.csv             # Stores recorded expenses
```
